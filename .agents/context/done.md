# Definition of done

A rule or runtime change is done when its public behavior, docs, catalog,
fixtures, and release surface agree; focused tests and the deterministic gate
pass; and the strict consumer type contract remains green.

The environment contract is done when all eight context packets are fresh and
linked, required commands and blocking gates are executable, secret-like paths
are absent, and Pre-CR includes the required contract adapter.

Registry-dependent evidence must be labeled separately from local evidence.
