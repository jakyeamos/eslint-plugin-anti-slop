# Security Policy

## Supported Versions

Only the latest published release line receives security fixes.

## Reporting a Vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jakyeamos/eslint-plugin-anti-slop/security/advisories/new). Do not include exploit details, credentials, or other sensitive material in public issues.

Include the affected version, impact, a concise reproduction or proof of concept, and any suggested mitigation. The maintainers aim to acknowledge reports within seven calendar days and will coordinate disclosure after a fix and credit plan are agreed.
